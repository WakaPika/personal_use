# 🎂 むくくん 1歳記念スライドショー動画

睦久（むく）くんの1歳のお誕生日（2025.8.9生まれ → 2026.8.9で1歳）を記念した、
ママへの感謝を込めたスライドショー動画（MP4）のジェネレーターです。

## 構成（約1分50秒・フルHD・オルゴール風BGM付き）

1. **タイトル** — お名前・誕生日入りのバースデータイトル
2. **成長の記録** — 生後0か月〜1歳までの月齢ごとの写真とひとこと（13枚）
3. **1年間のきろく** — 授乳・おむつ替え・寝かしつけ・吐き戻しのお着替えの回数カード
4. **吐き戻し回数のグラフ** — 月齢ごとにだんだん減っていった記録
5. **ママへのメッセージ** — パパからの感謝の手紙
6. **エンディング**

## 使い方

### 1. 写真を入れる

`photos/` フォルダに、**月齢の2桁数字で始まるファイル名**で写真を置きます。

```
photos/00.jpg   ← 生後0か月（新生児）
photos/01.jpg   ← 生後1か月
...
photos/12.jpg   ← 1歳になった日
```

- 対応形式: jpg / png / webp / HEIC（iPhone写真そのままOK）
- `06-うつぶせ.jpg` のように数字の後に説明を付けてもOK（先頭2桁で判定）
- 写真が無い月はかわいいイラストのプレースホルダーになります

### 2. 育児データ・文言を差し替える

`config.json` を編集します。

- `stats.cards` — 1年間の合計回数（**現在はサンプル値**。育児アプリの書き出しデータで置き換えてください）
- `stats.chart.monthly_values` — 月齢ごとの吐き戻し回数（0〜11か月の12個）
- `months[].caption` — 各月のひとこと
- `message.slides` — ママへのメッセージ（1スライド4行×2枚）

### 3. 生成する

```bash
pip install pillow numpy pillow-heif   # 初回のみ
python3 generate.py            # → output/muku_1st_birthday.mp4
python3 generate.py --slides   # スライド画像だけ生成（デザイン確認用）
```

ffmpeg と日本語フォントが必要です（フォントは `assets/fonts/` に同梱）。

## 育児アプリのデータについて

ぴよログ等の育児アプリから書き出したデータ（テキスト/CSV）を `data/` フォルダに
置いてClaudeに渡せば、集計して `config.json` に反映できます。
