## 🍚 すくすくごはん — 離乳食 栄養管理アプリ

`index.html` をブラウザで開くだけで使える、離乳食・ミルクの栄養管理ウェブアプリです。
外部ライブラリ・サーバー不要の単一HTMLファイルで、データはブラウザのローカルストレージに保存されます。

### 主な機能

- **1日の栄養目標の自動計算** — 生年月日・性別・体重を登録すると、月齢に応じた1日に必要な栄養素の目標量（エネルギー・たんぱく質・脂質・炭水化物・カルシウム・鉄・ビタミンA/D/C・亜鉛）を表示。体重による補正つき
- **食事ごとの記録** — 朝食・昼食・夕食・おやつ・ミルクの区分ごとに、食材とおおよその量（g / ml）を入力
- **食材ごとの栄養内訳** — 記録した食材をタップすると、含まれる栄養素と1日の目標量に対する割合を表示
- **ミルクにも対応** — 母乳・育児用ミルク・フォローアップミルク・牛乳を登録でき、ミルク由来の栄養も合算
- **達成状況メーター** — 栄養素ごとに1日の目標に対する達成率をリアルタイム表示
- **1日の総評** — 1日の終わりに、点数・よくとれた栄養素・不足栄養素・ミルクと食事のバランスなどを総評
- **おすすめ食材の提案** — 不足している栄養素に対して、月齢に合った食材と栄養士風のアドバイスを表示
- **履歴管理** — 日々の記録と達成率を一覧表示。過去の日付の記録・編集も可能

### 使い方

1. `index.html` をブラウザで開く（またはGitHub Pagesで公開）
2. 「プロフィール」タブでお子さまの生年月日・性別・体重を登録
3. 「記録」タブで食事やミルクを入力
4. 1日の終わりに「総評を作成する」ボタンを押す

### データの根拠と注意事項

- 栄養目標量は「日本人の食事摂取基準（2020年版）」の乳児・幼児の目安量/推奨量に基づく概算です
- 食品成分値は「日本食品標準成分表」に基づく概算です（100g / 100mlあたり）
- 本アプリは医療上のアドバイスを提供するものではありません。アレルギーや発育に関する心配は、かかりつけ医・保健師・管理栄養士にご相談ください
