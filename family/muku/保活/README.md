# 保活 — むくの保育園比較サイト

むく(2025年生まれ)の入園申請に向けて、検討中の保育園9園を夫婦で比較・管理するためのサイトです。

## 使い方

`index.html` をブラウザで開くだけで使えます(サーバー不要・スマホ対応)。

- **一覧比較**: 全園の空き状況・申請/内定数・定員・距離・夫婦の評価をひと目で比較。並び替えと「0歳受入園のみ」絞り込みが可能。
- **園の詳細**: 園ごとに月次の「空き / 申請数 / 内定数」を入力して記録。希望順位・見学ステータス・★評価(パパ/ママ別)・夫婦のメモを残せます。
- **使い方・共有**: 入力データの書き出し/読み込み(夫婦のスマホ間でLINE等を使って同期)。

入力データはブラウザのlocalStorageに自動保存されます(端末ごとに独立)。

### スマホで見る方法

- GitHubリポジトリの Settings → Pages でGitHub Pagesを有効にすると、URLでアクセスできます(**リポジトリが公開になる点に注意**)。
- もしくは `index.html` をLINEやAirDrop等でスマホに送って開くこともできます。

## 毎月の運用

1. 市の公表資料で最新の「受入可能数(空き)」「申請数・内定数」を確認する
   - [川崎市: 認可保育所等の受入可能数及び利用調整結果](https://www.city.kawasaki.jp/450/page/0000030624.html)(毎月更新・宮前区のPDFを見る)
   - [宮前区: 保育園総合情報](https://www.city.kawasaki.jp/miyamae/page/0000047766.html)
   - [横浜市青葉区: 保育情報](https://www.city.yokohama.lg.jp/aoba/kurashi/kosodate_kyoiku/hoiku/)(たまプラーザ側3園)
2. サイトの「園の詳細」タブで各園に月次データを転記する
3. 見学したらメモ・★評価・見学ステータスを更新する

## 前提メモ

- むくは2026年度は**0歳児クラス**、2027年度からは**1歳児クラス**
- 妻の育休延長のため、入所保留通知(不承諾)を見据えて**空きの少ない園に絞って申請**する方針
- 川崎市の途中入園申請の締切は**利用希望月の前月10日**(土日祝なら直前の開庁日)。申請先: 宮前区役所 児童家庭課(044-856-3258)
- たまプラーザ側の3園(ろりぽっぷ / 小学館アカデミー / グローバルキッズ)は**横浜市青葉区**の園のため、川崎市民は**管外(市外)申請**となり手続き・締切・優先順位が異なる

## 注意

`index.html` 内の定員・住所などの初期データはWeb情報(各園公式サイト等)をもとにした**参考値**です。「要確認」表記の項目や最新の空き状況は、必ず市の公表資料・園見学で確認してください。
